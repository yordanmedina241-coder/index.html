🏠 Bienvenidos

Esta página fue creada como parte de mi evaluación de Aplicaciones Web. Aquí podemos aprender sobre tecnología, computación, programación y desarrollo web.


💡 ¿Qué es la tecnología?

La tecnología permite crear herramientas, dispositivos y soluciones para facilitar las actividades de las personas. Actualmente está presente en la educación, empresas, comunicación, entretenimiento y muchos otros sectores.

📚 Temas de informática

💻 Computadoras

Dispositivos utilizados para procesar información y ejecutar diferentes programas.

🌐 Redes

Permiten conectar dispositivos para compartir información y recursos.

👨‍💻 Programación

Consiste en crear instrucciones para que los computadores realicen determinadas tareas.

🌎 Páginas web

Sitios que podemos visitar desde un navegador utilizando Internet.

🧑‍💻 Lenguajes utilizados

  1. HTML - Estructura de la página.
  2. CSS - Diseño y estilos.
  3. JavaScript - Interactividad.
